# AP-08 annotations
Branch: feat/ap-08-annotations; delivery: ask-on-risk; runner: npm test, npm run lint, npm run build.

## Specs
1. **S1**: “Anotaciones locales del analista sobre una zona, un punto o un transecto, con exportación e importación GeoJSON y un informe Markdown/PDF conforme al contrato existente.”
2. **S2**: “Permite crear y consultar anotaciones para las selecciones admitidas, con nota, autor y uno de los veredictos del contrato: Consistent with fire effects, Doubtful, Likely not fire-related o Needs field check. El veredicto se identifica como juicio del analista, no como clasificación o validación científica.”
3. **S3**: “Guarda localmente las anotaciones y una instantánea de la evidencia disponible al crearlas. Los datos ausentes se conservan como null o desconocidos según el contrato; no se fabrican métricas ni se usan colores del mapa como mediciones.”
4. **S4**: “Exporta e importa GeoJSON conforme a annotations.schema.json; exportar e importar conserva las anotaciones. Valida archivos incompatibles o dañados antes de modificar lo guardado y solicita una decisión explícita antes de reemplazar datos existentes.”
5. **S5**: “Genera un informe Markdown/PDF con mapa, tabla de anotaciones, método y fuentes disponibles. Conserva el aviso MOCK cuando corresponda y distingue observaciones, cautelas y juicios del analista.”
6. **S6**: “El almacenamiento es local, sin envío automático a servicios externos. Comunica errores de almacenamiento, importación y exportación sin borrar silenciosamente datos previos; los controles son accesibles con teclado.”
7. **S7**: “Las pruebas cubren persistencia, datos ausentes, exportación/importación, archivos inválidos, protección de datos existentes, informe, aviso MOCK y accesibilidad.”
8. **S8**: “Fuera de alcance: backend de anotaciones, sincronización remota, cambios de contrato y validación científica de los juicios.”
